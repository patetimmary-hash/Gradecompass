What actually moves your CGPA up:
• Show up to every class — attendance alone protects your grade
• Review the day's topic within 24 hours, not the night before exams
• Do practice questions, not just re-reading notes
• Form or join a small study group for tough courses
• Sleep and eat properly — tired reading doesn't stick
• Track which courses need more hours and rebalance weekly

How do I set this up? (one-time, ~5 minutes)
1. Go to console.firebase.google.com and sign in with any Google account.
2. Tap Add project, give it any name, finish the wizard.
3. In the left menu tap Build → Firestore Database → Create database → choose Start in test mode.
4. Tap the ⚙️ gear (top left) → Project settings → scroll to "Your apps" → tap the </> (web) icon → register an app (any nickname).
5. It shows a code block starting with const firebaseConfig = {"{"}...{"}"} — copy everything between the curly braces and paste it in the box below.
6. Pick any Sync Code below (e.g. your name + a number) — use the exact same code on every device you want this data to appear on.
